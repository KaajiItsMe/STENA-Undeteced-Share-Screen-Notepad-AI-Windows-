==================================================
        PANDUAN STEALTH NOTEPAD + AI
==================================================

Aplikasi ini didesain untuk berjalan di belakang layar secara rahasia (Stealth Mode) dan tidak akan muncul di Taskbar.

--- DAFTAR SHORTCUT (TOMBOL PINTAS) ---
1. Buka / Sembunyikan Aplikasi
   Tekan: Ctrl + Shift + B

2. Buka Tab Notepad Cepat
   Tekan: Ctrl + Shift + N

3. Buka Tab AI Chat Cepat
   Tekan: Ctrl + Shift + A

4. Simpan Teks Notepad Manual (Auto-save sudah aktif 1 detik)
   Tekan: Ctrl + S

5. Sembunyikan Aplikasi Secara Kilat (Panic Button)
   Tekan: Esc

--- SHORTCUT PINDAH POSISI (Hanya saat aplikasi terbuka) ---
6. Geser Jendela ke Atas
   Tekan: Ctrl + Shift + Panah Atas

7. Geser Jendela ke Bawah
   Tekan: Ctrl + Shift + Panah Bawah

8. Geser Jendela ke Kiri
   Tekan: Ctrl + Shift + Panah Kiri

9. Geser Jendela ke Kanan
   Tekan: Ctrl + Shift + Panah Kanan

10. Kembalikan Jendela ke Pojok Kanan Bawah (Reset Posisi)
    Tekan: Ctrl + Shift + R

11. Sembunyikan / Tampilkan Simbol Kursor Ketik (Anti-Caret Flicker)
    Tekan: Ctrl + Shift + C

--- FITUR BARU v1.0.0 ---
- Siap Pakai Langsung (Zero-Setup): Sudah dilengkapi Google Gemini 3.8 Flash bawaan yang aktif otomatis tanpa perlu konfigurasi API Key!
- Ekstrak Dokumen AI: Mendukung upload file PDF, Word (.docx, .doc), dan TXT via Drag & Drop atau klik tombol dokumen.
- Anti-Screen Record & Anti-Share Screen: Jendela dan hover tombol tidak tertangkap di Zoom / Teams / Google Meet / OBS / Discord.
- Tombol Salin Cepat: Tombol copy di pesan AI tanpa hover highlight yang mencurigakan.

--- PENGATURAN API (OPSIONAL) ---
Jika ingin memakai API Key pribadi (9Router / Groq), silakan buka file "API.txt" dan masukkan kunci Anda. Jika dibiarkan kosong, aplikasi tetap berjalan normal menggunakan AI bawaan.

--- JIKA SHORTCUT GAGAL ATAU ERROR ---
Terkadang, proses aplikasi lama mungkin masih berjalan tersembunyi (zombie process) di komputer Anda, sehingga membuat tombol shortcut tidak merespon saat aplikasi baru dibuka.



Solusi:
1. Klik dua kali (jalankan) file "fix.bat" yang ada di folder ini.
2. File tersebut akan secara otomatis membersihkan dan menutup paksa semua proses aplikasi yang error/nyangkut di memori.
3. Setelah jendela fix menghilang (selesai), Anda bisa membuka kembali aplikasinya secara normal.
